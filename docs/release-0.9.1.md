# Pavlusha 0.9.1

Исправления и улучшения после версии 0.9.0:

- Описания модулей и инструментов остаются в системных инструкциях при смене доступных действий; ограничения на вызов проверяются отдельно.
- Уточнены инструкции для GUI и фоновых процессов при работе с локальным браузером.
- Добавлены `run-pavlusha.sh` для запуска с подготовленным Python-окружением и `check-browser.sh` для проверки браузера.
- Добавлено [руководство по настройке браузера](browser-setup.md).

Дополнительные сведения об архитектуре и ограничениях предыдущего выпуска — в [описании 0.9.0](release-0.9.0.md).
