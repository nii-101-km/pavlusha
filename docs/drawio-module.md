# Draw.io

Модуль `pavlusha_modules.drawio:create_extension` сохраняет родной XML в новый
`.drawio`-файл и экспортирует первую страницу в PNG через локальный draw.io Desktop.
Павлуша может проверить картинку инструментом `view_image` из модуля `images`.
Все пути указываются относительно рабочей папки; существующие файлы не перезаписываются.

В настройке `executable` можно указать полный путь к исполняемой программе
draw.io или AppImage; иначе используются `drawio` или `draw.io` из PATH.
Файл AppImage должен иметь разрешение на исполнение. Модуль включает режим
извлечения AppImage при запуске. Для экспорта требуется доступная графическая
среда. Поддержка MCP не требуется.

Desktop запускается как процесс пользователя вне песочницы Павлуши и наследует
окружение процесса. Ограничение путей относится к путям инструментов, а не к
полномочиям самой программы или её дочерних процессов; сетевой доступ Desktop
этим модулем не отключается. Используйте доверенную установку draw.io и файлы.
Тайм-аут ограничивает ожидание запуска экспорта, но отдельная проверка завершения
всех процессов Electron после тайм-аута не выполняется.

`drawio_save` принимает полный XML с корнем `mxfile` и несжатой страницей
`diagram/mxGraphModel/root`. Изменение схемы выполняется сохранением нового
файла с изменённым XML; это не управление уже открытым окном Desktop. Проверка
XML не гарантирует правильность расположения или содержимого схемы — результат
нужно открыть и визуально проверить.
