# Project Map как внешний модуль

`project_state_agent.py` подключает Shell, Project State и Project Map.
Map использует общий контракт v2 без предметных правил в ядре. Зависимости для индексации перечислены в
`requirements.txt`: Tree-sitter и грамматика Python.

`pavlusha_modules.project_map.ProjectMap(workdir)` использует прежний индексатор,
перенесённый из сохранённого кода. Индекс содержит Python-файлы, классы, функции,
сигнатуры и диапазоны строк; семантической памяти и собственных инструментов нет.

На `session_started` модуль загружает hash-кэш из
`session_dir/modules/project_map/map.json`, сверяет его с текущими файлами и
публикует префикс `project_map/navigation`. На `prepare_turn` с новой эпохой
контекста заново сверяет файлы и заменяет снимок. Обычные тюрны не меняют префикс.
При возобновлении процесса всегда проверяются актуальные файлы, даже если
техническая история сохранилась. Переполнение не откатывает карту к State:
после сброса она строится по текущему дереву файлов.

Project State автоматически скрывает карту во время инициализации и review
через общий exclusive-механизм. Map не знает правил State, не запрашивает сбросов
и не препятствует им. Данные карты не попадают в состояние Project State.

Сохранены hash-кэширование, пропуск генерируемых каталогов и символических ссылок,
пометки ошибок разбора. Кэш восстанавливаемый: источником истины служат файлы.
Индексируются только `.py`, как и в прежней реализации.

Проверки: `tests/test_project_map.py` и `tests/test_project_map_module.py`.
