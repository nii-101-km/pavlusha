# Общие сервисы модулей

`pavlusha_modules.services` — общий Python-интерфейс для доверенных модулей,
а не дополнительный модуль Pavlusha или часть событийного ядра. Он скрывает
расположение внутренних реализаций в `bundled`; вызывающие модули не обязаны
подключать друг друга или импортировать закрытые файлы друг друга.

- `ProcessManager(workdir, allow_network=False, allow_kvm=False)` управляет
  только процессами, созданными данным экземпляром. `call` принимает действия,
  проверенные через `validate_process_action`; настройки доступа задаются
  создателем. Владелец создаёт менеджер при запуске сессии и вызывает `close()`
  при завершении. Идентификаторы не переносятся между сессиями.
- `read_image(path, workdir)` возвращает метаданные и блок изображения или
  метаданные ошибки и `None`. Путь ограничен рабочим каталогом; допустимые
  форматы и размеры проверяются реализацией. `validate_view_image_action`
  проверяет аргументы инструмента просмотра изображения.

Сервисы — обычные вызовы Python в доверенном коде. Они не являются защитной
границей для недоверенных модулей и не заменяют событийный контракт
[ядра](event-interface.md). Доступ сети и KVM выдаётся конкретным запускам
с учётом настроек их владельца; загрузка модуля не делает Python-код песочницей.
