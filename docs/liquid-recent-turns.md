# Liquid: окно контекста и последние сообщения

Для сборки используйте конфигурацию `examples/liquid.cpu.config.json`: бюджет
контекста в ней составляет 7000 токенов, а порог начала сброса — 0,5 окна.
Сервер модели настроен на окно 8192 токена.

Сборка включает Shell, Finish, детектор повторов и Token Window. Модуль
переносит последние сообщения по долям окна (0,25 и 0,4), пользуясь
токенизатором llama-server. Суммаризация и сохранение блоков кода не
подключены. При превышении допустимого размера одного сообщения происходит
полный сброс истории; файлы рабочего каталога сохраняются.
