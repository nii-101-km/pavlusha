# Небольшая сборка для Liquid

`examples/liquid.cpu.config.json` подключает Shell, Finish, детектор циклов
и Token Window. Эти модули можно использовать и с другими моделями.
Не подключайте одновременно Finish и
другой модуль, владеющий действием `finish`, например Project State: конфликт
обнаруживается до отправки запроса.

Finish предоставляет действие `finish` с непустым итогом и завершает сессию.
Он не проверяет, действительно ли выполнена задача: результаты проверяются
отдельно. Само ядро и другие владельцы `finish` не изменены.
